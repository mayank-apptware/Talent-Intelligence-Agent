# Phase 4 - Opportunity Discovery

## Goal

Discover roles, projects, and learning opportunities relevant to an employee's skills.

## Flow

Employee Profile
→ Skills
→ Opportunity Search
→ Evidence
→ Candidate Opportunities

## CCAR-F Concepts

- Tool use
- MCP
- Tool descriptions
- Tool selection
- Tool restrictions
- Resources vs tools
- Parallel research

## Human Must Implement

- Opportunity-agent architecture
- Tool requirements
- Tool schemas
- Search strategy
- MCP design decisions
- Evidence requirements

## AI May Implement

- API clients
- Database adapters
- Search utilities
- Test infrastructure

## Exercises

1. Search a local opportunity database.
2. Add multiple opportunity sources.
3. Expose appropriate data as MCP resources.
4. Expose actions/search operations as MCP tools.
5. Test incorrect tool selection.
6. Improve tool descriptions.

## Completion Criteria

The system retrieves relevant opportunities efficiently while clearly separating MCP resources from tools.
