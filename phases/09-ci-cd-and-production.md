# Phase 9 - CI/CD & Production

## Goal

Automate safe Claude Code workflows in CI/CD.

## CCAR-F Concepts

- Non-interactive Claude Code
- Permission modes
- Turn limits
- Cost controls
- Automated code review
- Structured output
- Iterative refinement
- Test generation

## Human Must Implement

- CI safety boundaries
- Permission strategy
- Cost/turn limits
- Review criteria
- Required project standards
- Automated review output schema

## AI May Implement

- CI configuration boilerplate
- Scripts
- Test runners
- Report formatting

## Exercises

1. Run Claude Code non-interactively.
2. Apply permission restrictions.
3. Add cost/turn limits.
4. Run automated code review.
5. Generate tests using existing tests as context.
6. Feed failures back for iterative refinement.
7. Produce structured CI output.

## Completion Criteria

Claude Code can participate in CI/CD without uncontrolled execution and produces predictable, machine-processable results.
