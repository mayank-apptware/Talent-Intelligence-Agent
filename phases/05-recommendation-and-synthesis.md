# Phase 5 - Recommendation & Synthesis

## Goal

Generate evidence-backed opportunity recommendations without hiding uncertainty.

## Flow

Skills + Opportunities + Evidence
→ Synthesis Agent
→ Recommendation
→ Confidence + Gaps + Uncertainty

## CCAR-F Concepts

- Structured output
- Synthesis agents
- Source metadata
- Conflicting evidence
- Uncertainty preservation
- Specialized review passes
- Human review routing

## Human Must Implement

- Recommendation schema
- Matching criteria
- Synthesis prompt
- Evidence requirements
- Confidence semantics
- Uncertainty handling
- Review criteria

## AI May Implement

- Formatting
- Storage
- API/UI integration
- Test infrastructure

## Exercises

1. Generate a recommendation from clear evidence.
2. Introduce conflicting evidence.
3. Introduce missing evidence.
4. Prevent unsupported claims.
5. Route low-confidence cases to human review.
6. Separate security/business/API-style review concerns where applicable.

## Completion Criteria

Recommendations clearly distinguish evidence, inference, uncertainty, and missing information.
