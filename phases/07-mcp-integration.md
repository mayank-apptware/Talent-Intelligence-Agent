# Phase 7 - MCP Integration

## Goal

Integrate external talent data through MCP.

## CCAR-F Concepts

- MCP servers
- MCP tools
- MCP resources
- Server scopes
- Authentication
- Environment-variable expansion
- Tool discovery
- Tool descriptions

## Human Must Implement

- MCP architecture
- Resource/tool decisions
- Authentication configuration
- Tool schemas
- Tool descriptions
- Server scope
- Discovery verification

## AI May Implement

- MCP boilerplate
- Supporting types
- Test utilities
- Documentation

## Exercises

1. Build a small talent MCP server.
2. Expose employee data as resources.
3. Expose search operations as tools.
4. Configure authentication.
5. Verify tool discovery.
6. Deliberately misconfigure the server and diagnose it.

## Completion Criteria

The agent reliably discovers and uses the correct MCP resources and tools.
