# Phase 6 - Context & State Management

## Goal

Make long-running Talent Intelligence workflows resumable and context-efficient.

## CCAR-F Concepts

- Context windows
- Summarization
- Sliding windows
- Scratchpad files
- Structured state
- Session resumption
- Context injection
- Targeted re-analysis

## Human Must Implement

- State structure
- Persistence strategy
- Resume strategy
- Context selection
- Summarization strategy
- Re-analysis rules

## Exercises

1. Interrupt a workflow.
2. Resume it without repeating completed work.
3. Modify one source document.
4. Identify what must be re-analyzed.
5. Inject previous findings into a resumed session.
6. Compare full-context and targeted-context approaches.

## Completion Criteria

The workflow can resume accurately while minimizing repeated work and unnecessary context.
